# Spielwiese 🌿

Ein Desktop-Launcher für kleine Spiele: eine Pixel-Art-Wiese, die sich mit der Tageszeit verändert, und darauf Holzschilder, hinter denen jeweils ein Spiel steckt.

Die Spiele sind eigenständige HTML/JS-Spiele, angelehnt an bekannte Spielprinzipien, aber mit eigenem Namen und eigenem Aussehen.

## Technik

- **Spiele und Oberfläche:** HTML, CSS, JavaScript (ohne Framework)
- **App-Hülle:** [Tauri 2](https://tauri.app) (Rust + WebView2)
- **Verteilung:** Windows-Installer (NSIS, ohne Admin-Rechte) mit automatischen, signierten Updates über GitHub Releases
